# Made-up Zepp export sample

All values here are **made up**. These files copy the layout of a real Zepp "Export personal data" archive (SCRUM-10, 2026-10-17): the same folder and file names, headers, UTF-8 BOM, LF line endings, `null` literals, the escaped `naps` JSON and the mix of time formats. They are cut down to a few rows each, for parser tests. No real data is in the repo (ADR-0005).

The real archive is a password-protected ZIP. These samples are unzipped, and the timestamp in the file names is a placeholder. See [zepp-export.md](../../zepp-export.md#b2-confirmed-export-format) for what each file means.
