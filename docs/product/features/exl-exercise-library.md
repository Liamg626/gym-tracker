# EXL: Exercise Library

The repo-owned catalogue of Exercises and the Muscles they work (ADR-0006).

## Stories

**EXL: Liam's exercise list** (MVP, Task, `ready-for-human`)
- Liam writes the list of Exercises he does, along with his gym's equipment
- Blocks the library generation story

**EXL: Muscle taxonomy** (MVP, Task)
- Research and define the list of Muscles at anatomical detail (e.g. deltoid anterior/lateral/posterior part), each with a stable ID, display name, front/back side and a roll-up group for summaries
- Findings and the proposed list in `docs/research/muscle-taxonomy.md`: 46 Muscles in 11 Muscle Groups (after SCRUM-22), each mapped to one or more Recovery Map Regions
- Decide how Muscles with no shape in the Recovery Map artwork (e.g. rhomboids, sartorius, peroneals) get a Region; see `docs/research/anatomical-svg.md`

**EXL: Library schema and validation** (MVP)
- JSON schema plus a typed loader in `packages/exercise-library`
- Each Exercise: stable ID, name, equipment, Primary Muscles, Secondary Muscles, `bodyweight` flag, `countsBothSides` flag, weight step (e.g. 1.25 / 2.5kg)
- A test fails if any Muscle ID is unknown, an ID is duplicated, or an Exercise has no Primary Muscle
- The Muscle list (ID, display name, side, Muscle Group) lives in the library package alongside the Exercises
- A test fails if a Muscle has no Region or a Region has no Muscle (ADR-0006)

**EXL: Generate the library** (MVP, blocked by the two stories above)
- Every entry in `docs/research/exercise-list.md` goes into the library
- Muscle tags come from SCRUM-22 Phase 2 (`docs/research/exercise-muscle-tags.md` and `exercise-library.draft.json`, generated by `scripts/exercise_tags.py`): researched once per family, with a variant overriding them only where sources show its Muscles differ (e.g. incline vs flat press, leg press foot position, hammer vs supinated curl); the JSON stores complete Primary and Secondary tags on every Exercise
- Cite sources in the PR
- Exercises are never removed (ADR-0006)

**EXL: Exercise picker** (MVP)
- Search by name, filter by Muscle Group, Muscle or equipment, recently used Exercises first
