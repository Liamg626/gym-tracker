# Exercise Library is a repo-owned JSON file

The Exercise Library, with each Exercise's Primary and Secondary Muscles, is a version-controlled JSON file in the repo, researched and generated for the Exercises Liam actually does. There is no in-app "add exercise" screen: new Exercises are added by editing the file here. This keeps Muscle tagging researched and reviewable. Exercises are never removed or retired, so historical Workouts always resolve, and Muscle IDs in the file must match region IDs in the Recovery Map SVG.
