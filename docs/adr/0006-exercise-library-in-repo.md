# Exercise Library is a repo-owned JSON file

The Exercise Library, with each Exercise's Primary and Secondary Muscles, is a version-controlled JSON file in the repo, researched and generated for the Exercises Liam actually does. There is no in-app "add exercise" screen: new Exercises are added by editing the file here. This keeps Muscle tagging researched and reviewable. Exercises are never removed or retired, and Muscle IDs are never removed or renamed, only added, so historical Workouts always resolve. Every Muscle ID in the file must appear on at least one Region of the Recovery Map, and every Region must carry at least one Muscle ID; a Region may carry several. (Amended 2026-10-17 after the Muscle taxonomy research, `docs/research/muscle-taxonomy.md`.)
