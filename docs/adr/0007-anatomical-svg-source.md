# Recovery Map artwork is react-native-body-highlighter's path data, restyled as a fitness-style body

Status: accepted (Liam, 2026-10-17)

The Recovery Map is drawn from the front and back path data of react-native-body-highlighter by ELABBASSI Hicham, MIT licence. Liam chose it over the more detailed Commons "Muscles front and back" medical illustration (CC BY-SA 4.0) because he wanted a fitness look: separated muscle blocks and a wide stance (see `docs/research/anatomical-svg.md`). We copy only the shapes into our own SVG file. We rotate the legs outward at the hip, strip every original colour so all muscles start grey, and give each Region one or more Muscle IDs so the component can colour it by Recovery State. Deltoid, chest, trapezius and biceps are cut into heads. Muscles with no shape (e.g. brachialis, sartorius) are handled in the Muscle taxonomy. The MIT copyright and permission notice stays in the SVG file and the README's third-party notices, and the app's About screen carries a credit line. The artwork's original source is undocumented, so if a conflicting source turns up, the fallback is the Commons illustration kept as a separate CC BY-SA file.

Amended 2026-10-18 (SCRUM-22): Liam re-confirmed this source over body-muscles (Apache-2.0) after a side-by-side. The production file is `assets/recovery-map/recovery-map.svg`, built from a pinned commit by `scripts/build_recovery_map.py`. The cuts follow the source geometry: deltoids as curved bands along the cap (front + side delt on the front view, rear + side delt on the back), the back trapezius on a diagonal into an upper-traps wedge and a rhomboids strip, and the back neck shapes now carry the upper traps instead of staying neutral. Later the same day Liam merged the biceps into one Muscle and one Region, so the biceps shape is no longer cut.
