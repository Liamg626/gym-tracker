# Recovery Map artwork is react-native-body-highlighter's path data, restyled as a fitness-style body

Status: proposed (draft awaiting Liam's approval)

The Recovery Map is drawn from the front and back path data of react-native-body-highlighter by ELABBASSI Hicham, MIT licence. Liam chose it over the more detailed Commons "Muscles front and back" medical illustration (CC BY-SA 4.0) because he wanted a fitness look: separated muscle blocks and a wide stance (see `docs/research/anatomical-svg.md`). We copy only the shapes into our own SVG file. We rotate the legs outward at the hip, strip every original colour so all muscles start grey, and give each region a Muscle ID so the component can colour it by Recovery State. Deltoid, chest, trapezius and biceps are cut into heads. Muscles with no shape (e.g. brachialis, sartorius) are handled in the Muscle taxonomy. The MIT copyright and permission notice stays in the SVG file and the README's third-party notices, and the app's About screen carries a credit line. The artwork's original source is undocumented, so if a conflicting source turns up, the fallback is the Commons illustration kept as a separate CC BY-SA file.
